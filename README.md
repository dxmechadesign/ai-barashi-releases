# AI バラシ 配布

iCAD SX の組立モデルから部品図を作成する Windows アプリ「AI バラシ」のインストーラーと、更新情報の置き場所です。

## 入手

[Releases](../../releases/latest) から `AI-Barashi-<版>-x64.msi` をダウンロードして実行します。

## 利用に必要なもの

- ライセンスファイル（発行元から受け取ります。インストーラーだけでは動きません）
- ライセンスに登録された ChatGPT アカウント
- iCAD SX がインストールされた Windows 11（64 ビット）

## 更新

アプリは起動時にこの場所の `update.json` を確認し、新しい版があれば知らせます。更新を実行するかどうかは利用者が決めます。確認の際、利用者・PC・ライセンスを識別する情報は送りません。

## 注意

- インストーラーにコード署名はありません。実行時に Windows の警告が表示されることがあります。
- ソースコードはこのリポジトリにありません。
